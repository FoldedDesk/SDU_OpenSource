## 事实、规划及报价范围

现有代码是使用合成数据的本地规则 demo，未连接真实 OMS/WMS/客服台，也未调用大模型。表中54实施人天是从该原型扩展至受控试点的**拟交付工作量估算**，不是已发生的开发工时。

本轮默认选用“内网规则辅助”，规划20名内部试点用户、峰值10并发、6周交付、验收后12个月服务。真实企业规模、访问授权、部署环境、接口条件与用户数仍待业务确认。报价为未签章测算草案，签约主体、发票信息和具体税率须在签约时确认。

方案2“脱敏云API”只有在获得上云授权后才可启用，模型费及适配人天都必须同步更新。方案3为本地小模型设备预算，不能视为完整 DeepSeek-V3.2 模型的运行配置；需选型、询价并压测。

所有金额按预算支出与对客含税报价分别列示，不处理进项税抵扣或所得税。人力成本、报价单价、差旅、内部资源分摊、支持工作量及风险准备金比例均为明确标注的估算，不代表已取得供应商报价或已发生支出。

## 业务量、Token及ROI口径

- 访谈中的每日1,500个退货包裹，不等于每日1,500次咨询或模型调用。日均全部售后咨询600次是本轮独立假设。
- 状态催问占比42%、查询约4分钟/次来自训练访谈，尚待样本验证；20%占比是访谈目标，1分钟/次是拟改善假设。月工作日按22天，运营期按12个月。
- 云API备选采用70%覆盖率、每咨询1.2次调用、5%附加重试、每调用6,000输入与800输出Token。不计免费额度、Batch或缓存优惠。预算为每月4,890次调用、70.42元/月、845.04元/年；默认规则方案模型费仍为0元。
- 释放工时按50元/小时折算，首年容量价值195,360元。只按30%假设兑现为收益，即58,608元。新增复核按0.25小时/日、80元/小时计入，不重复从工时价值中扣除。
- 默认假设下首年净收益为 **−46,942元**，首年ROI约 **−44.5%**。持续年度净收益36,528元，简单回本期约 **27.4个月**。这些是测算结果，不是已实现收益或回本承诺。
- 回本按一次性实施及客户内部培训全额先投入、年度服务及复核成本按月均摊，未计建设期收益。合同30%/40%/30%分期付款会使逐笔现金流回本时间有所不同。

各工作簿内部使用公式，可独立打开重算；**跨文件使用同版本的上游结果快照，不含实时外部工作簿链接**。蓝色数字与浅黄底为可修改输入。修改一份文件不会自动改写其他文件，必须按以下位置同步。
